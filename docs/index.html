Visual Memory Wiki: Interactive Figure

A paper-style interactive explanation of the experiment: Markdown notes become image cards, short visual cues retrieve nodes in a shared coordinate space, and each retrieved node points back to source text.

1. Upload notes

Markdown chunks are treated as source-grounded knowledge units.

2. Make image handles

Each chunk receives a visual card. The image is an address, not a fact.

3. Embed cards

CLIP places image cards into a visual coordinate space.

4. Query by cue

An LLM should compress task context into a short visual cue.

5. Read sources

The AI reads attached source notes, not generated image details.

Figure 1. Visual Memory Wiki as a source-grounded visual retrieval loop. Generated image cards improved short-cue retrieval in the tiny demo, but long task prompts degraded CLIP matching. The design implication is that an LLM should first distill the work context into a short visual cue, then retrieve image nodes, then read the attached source Markdown.
